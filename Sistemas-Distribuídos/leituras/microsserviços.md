# O que são microsserviços?

> https://www.redhat.com/pt-br/topics/microservices/what-are-microservices

- Tipo de arquitetura de aplicações
- Serviços se comunicam por APIs
- Abordagem nativa em nuvem
- Função principal de cada aplicação é executada de maneira independente

## Arquitetura de microsserviços ou arquitetura monolítica
- Monolítica: Tudo é acoplado, é difícil escalar
- Microsserviços: Mudanças no sistema não exigem interrupção da aplicação na sua totalidade

## SOA vs microsserviços
- Microsserviços: Escopo de aplicação; Estratégia de implantação para cada aplicação
- SOA: Escopo empresarial; Interoperabilidade em toda a empresa

## Características
- Escalabilidade
- Geração de logs
- Monitoramento
- Depuração
- Conectividade
- Mais agilidade
- Resiliência

## Ferramentas 
- APIs
- Containers e Kubernetes
- Transmissão de eventos
- Computação serverless
  - Serverless: Sem servidores; Modelo de computação em nuvem onde o dev não se preocupa com gerenciamento de servidores
  - Devs somente empacotam o código em containers para a implantação
