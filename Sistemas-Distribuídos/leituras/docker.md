# Docker: desenvolvimento de aplicações em containers

> https://www.redhat.com/pt-br/topics/containers/what-is-docker


## Como o Docker funciona?
- Utiliza o kernel do Linux para segregar processos
- Empacota apps e dependências em imagens, que depois são instanciadas como containers

## Docker vs containers Linux tradicionais (LXC)
- O Docker melhorou a usabilidade do LXC com novas camadas.
